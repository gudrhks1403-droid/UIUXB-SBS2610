문제 3 해설 - flex-direction / gap

정답 코드

.menu {
    display: flex;
    flex-direction: column;
    gap: 20px;
}

설명

flex-direction 방향에는 두 가지 방향이 있습니다. 기본값은 row이고, column을 사용하게 되면 세로 레이아웃으로 사용됩니다.

현재 상황에서 flex-direction: column을 사용하면 가로(row)로 붙어 있던 버튼들이 세로(column) 방향으로 변형되면서 위에서 아래로 쌓이는 결과를 가질 수 있습니다.

여기에 gap: 20px을 사용하면 아이템과 아이템 사이에만 20px의 빈 공간이 생기면서 버튼끼리 일정한 간격을 가진 메뉴가 완성됩니다.

기억하기
row = 가로 (기본값), column = 세로
gap은 아이템 사이 간격만 만들어서, 맨 위·맨 아래에는 여백이 생기지 않아요. (margin보다 간편!)
