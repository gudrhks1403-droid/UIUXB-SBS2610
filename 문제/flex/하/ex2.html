문제 2 해설 - justify-content / align-items

정답 코드

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}

설명

flex에는 정렬 방향이 두 가지 있습니다. 아이템이 놓이는 방향인 주축(기본값 row = 가로)과, 그와 수직인 교차축(세로)입니다.

속성정렬하는 방향 (기본 row 기준)
justify-content주축 → 가로 정렬
align-items교차축 → 세로 정렬

현재 상황에서 justify-content: center와 align-items: center를 함께 사용하면 박스가 가로로도 가운데, 세로로도 가운데로 변형되면서 회색 영역의 정가운데에 놓이는 결과를 가질 수 있습니다.

기억하기
세로 가운데 정렬이 보이려면 부모에게 높이가 있어야 해요. (이 문제에서는 height: 300px)
"가로는 justify, 세로는 align" 이 두 줄은 정가운데 정렬의 공식처럼 자주 쓰입니다.
