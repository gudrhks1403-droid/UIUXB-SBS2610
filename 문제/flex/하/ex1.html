문제 1 해설 - display: flex

정답 코드

.container {
    display: flex;
}

설명

div는 기본적으로 block 요소라서 한 줄을 통째로 차지합니다. 그래서 박스 3개가 위에서 아래로 쌓여 있었습니다.

현재 상황에서 부모인 .container에 display: flex를 사용하면 .container는 flex 컨테이너로, 안에 있는 박스들은 flex 아이템으로 변형되면서 박스 3개가 가로로 나란히 놓이는 결과를 가질 수 있습니다.

기억하기
flex는 부모에게 줍니다. 자식(.box)에게 주는 것이 아니에요!
flex의 기본 방향은 row(가로)라서 display: flex 한 줄만으로 가로 배치가 됩니다.
