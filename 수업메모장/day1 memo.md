### 2. 핵심 개념 정리

개념 1. 로컬 저장소 (Local)

정의: 내 컴퓨터에 있는 저장소

사용하는 이유: 컴퓨터에서 작업한 파일을 저장하고 관리하기 위해 사용

작동 원리: 내 컴퓨터에 파일을 저장

실제 사용 사례: 학원 컴퓨터에 작업 파일 저장하기

개념 2. 원격 저장소 (Remote)

정의: GitHub에 있는 저장소

사용하는 이유: 다른 컴퓨터에서도 파일을 확인하고 관리하기 위해 사용

작동 원리: GitHub에 파일을 업로드하여 보관

실제 사용 사례: 학원에서 작업한 파일을 GitHub에 보관하고 집에서 로그인하여 확인하기
